# Project summary

### [Codex Repair](https://github.com/KevinJiang05/codex-repair)

技术：C# · WinForms · PowerShell · SQLite

面向 Codex 历史会话 provider 状态不一致的 Windows 诊断与修复工具，支持三层状态检查、批次备份与定点恢复，并提供脚本包和自包含便携版。

English alternative:

A Windows utility for diagnosing and repairing inconsistent provider metadata in Codex history, with three-store inspection, batch backups, targeted restore, and self-contained releases.
